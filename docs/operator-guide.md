# Operator Guide

## First Deployment

1. Define the operator's service area and intake process.
2. Define consent and purpose categories for candidate/employer data.
3. Run synthetic operating cases.
4. Enable human-reviewed sign-off for `:high`/`:safety-critical` actions and
   for every `:flag-compliance-concern` proposal.
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- consent and disclosure log
- safety-critical escalation path
- provenance for all operating records
- human review for high-risk cases and every compliance-concern flag
- audit export for all gated actions
- independent verification of every candidate/employer record before any
  proposal referencing it can commit or escalate

## Certification

Certified operators must prove that the governor gates every safety-critical
robot action, that safety-critical risks escalate to humans, and that the
actor's closed proposal-op allowlist can never finalize a hiring decision, a
candidate-rejection decision, or any placement decision that could
constitute discriminatory screening.
